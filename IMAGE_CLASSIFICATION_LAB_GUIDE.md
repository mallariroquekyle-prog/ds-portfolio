# New lab: Image Classification Using Pre-trained Models

## Added to the portfolio

- `labs/Lab_Image_Classification_Pretrained_Models.ipynb`
- Added the notebook to `_toc.yml` and linked it from the homepage.
- Five classifiers: ResNet-18, MobileNetV3-Small, EfficientNet-B0, SqueezeNet1.1, and ShuffleNetV2 x1.0.
- Custom Dataset + DataLoaders, dataset quality/size checks, five models, evaluation scores, comparison charts, confusion matrix, prediction gallery, and autogenerated interpretation.

## How to run in Windows

1. Extract the ZIP; open Command Prompt in the `my-portfolio` folder.
2. Install packages with `python -m pip install "jupyter-book<2" notebook torch torchvision pillow numpy pandas matplotlib scikit-learn ipython`.
3. Run `cd labs` then `jupyter notebook` (or `jupyter lab` if installed).
4. Open `Lab_Image_Classification_Pretrained_Models.ipynb` and choose **Kernel → Restart & Run All**. First execution needs internet to fetch the official PyTorch ants/bees dataset and pretrained weights. The downloads may take time depending on your connection.
5. Save the executed notebook (Ctrl+S) so the tables, plots, and analysis appear in Jupyter Book. Check results against the actual output; add a personal reflection in the final cell.
6. Return to the portfolio folder (`cd ..` in Command Prompt), run `jupyter-book clean .` then `jupyter-book build .`.
7. Preview via `start _build\html\index.html`, then commit and publish the folder in your existing Git repository.

## Requirements and important limitations

- The ZIP intentionally DOES NOT include the dataset or the pretrained model weights. They download automatically on first run; large files should not be committed to GitHub.
- If automatic dataset download fails, download `https://download.pytorch.org/tutorial/hymenoptera_data.zip` in a browser and extract to `labs/data/` such that `labs/data/hymenoptera_data/val/ants/` exists.
- The existing Jupyter Book config uses `execute_notebooks: off`, so the new notebook's plots and metrics WILL NOT appear on your website unless you run and save the notebook in Jupyter first.
- Accuracy and F1 are calculated by selecting **only two ImageNet category logits** (`ant` and `bee`) for a closed-set classification task. This is not an unrestricted 1,000-class top-1 evaluation or a fine-tuned model.
- The full dataset is a public PyTorch tutorial example; cite the source, and don't claim to have collected it yourself.
- Your actual scores will depend on the downloaded pre-trained weights and installed libraries. **No scores have been invented or pre-filled.**
